# Codex Auto Supervisor v1.0.0

First packaged release of the external, configuration-free Codex thread supervisor.

## Included

- Explicitly registered thread monitoring from local Codex session JSONL.
- Coordinator wake-up on completion, failure, approval requests, and async questions.
- Durable byte offsets and event deduplication.
- Optional CLI plus a Codex skill, with no Codex configuration changes and no startup entry.
- Chinese and English installation guides.

## Install

1. Download codex-auto-supervisor-v1.0.0.zip.
2. Extract the single codex-auto-supervisor directory.
3. Copy that directory into %USERPROFILE%\.codex\skills\. If CODEX_HOME is set, use %CODEX_HOME%\skills\.
4. Confirm that SKILL.md exists inside the copied directory.
5. Restart Codex or reload skills.
6. In a chat, invoke $codex-auto-supervisor and specify the target and coordinator threads.

Requirements: Windows, Python 3.11 or newer, and a running Codex desktop or compatible app-server.

The release ZIP contains only the runtime skill and its installation scripts. Tests and development metadata are excluded.
